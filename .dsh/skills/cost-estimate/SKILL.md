# cost-estimate —— 成本核算

## 何时用
用户说「估成本」「这次分析多少钱」「预算够不够」「cost estimate」。

## 单价（每百万 tokens，元；核对日期 2026-09-23）
- `deepseek-flash` 闲时：输入 1 / 输出 4；缓存命中输入 0.02。
- 高峰 = 工作日 9:00–12:00、14:00–18:00（北京时间），单价 ×2。

## 步骤
1. 取本次 Run 的 token 统计（或按计划 09 预算：L1≈2000/L2≈4000/L3≈8000 输入，输出 ≈25%）。
2. 按各等级单价计算，区分**缓存命中/未命中**与**峰谷**。
3. 汇总单次成本；乘调用次数得月度估算。

## 输出格式
| 等级 | 输入 tokens | 输出 tokens | 单价(闲/峰) | 成本(元) |
|---|---|---|---|---|

结论：单次约 ¥X；月度（N 次）约 ¥Y；与 `MONTHLY_BUDGET` 对比是否安全。

## 失败处理
缺 token 统计 → 用计划默认值并在结论标注「估算值」。
